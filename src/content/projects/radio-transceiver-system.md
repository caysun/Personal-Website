This year's challenge for the rocket team's LP&C (Liquid Propulsion & Controls) subdivision is to build a VTVL liquid base propellant rocket. I work on the avionics and control side logic for this project.

For the radio transceiver system, I modified a PCB to incorporate a duplex LoRa setup using KiCad. The portfolio shows the ground station 3D PCB layout, the ground station PCB editor view, radio signal tuning driver code, and telemetry packetization.
